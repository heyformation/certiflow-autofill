1. Executive Summary & Project Overview

1.1 Executive Summary

CertiFlow AutoFill is an enterprise-grade document automation, candidate evaluation, and certificate generation platform built specifically for French professional training centers and certification authorities (specifically Proforma Institut and Proskills Institut). Operating on live data ingested exclusively from the AUTOMATISATION tab of official EDOF spreadsheet registers (EDOF.xlsx / Developer of EDOF_restructure_v9.xlsx), CertiFlow automates candidate completeness validation, seed-reproducible pedagogical evaluation, mark threshold verification, multi-template Word (.docx) content-control assembly, high-fidelity PDF rendering, and automated cloud backup.

By integrating Artificial Intelligence (Anthropic Claude 3.5 Sonnet / Claude AI Engine), CertiFlow eliminates manual data copy-paste errors, ensuring that candidate portfolios, evaluation sheets (Grille d'Évaluation), jury transcripts (Procès-Verbal de Jury), and completion certificates (Attestations de Formation) are generated with 100% accuracy and full compliance with French RNCP and RS regulations.

1.2 Key Objectives & Value Proposition

  • Single Source Data Ingestion: Ingests candidate data from the AUTOMATISATION tab of EDOF.xlsx, ignoring legacy direct tabs.
  • Completeness Detection: Pure TypeScript engine checking candidate identity, session dates, contact info, and experience.
  • Dual Pipeline Support: Automatically classifies candidates into PRET_GENERATION_CLASSIQUE or PRET_GENERATION_WEDOF.
  • Correlated Pedagogical Chain: Seed-reproducible scoring linking Needs Assessment ➔ Placement Test ➔ Eligibility ➔ Presentation File ➔ Evaluation Grid ➔ PV de Jury.
  • Guaranteed Pass Floor: Enforces minimum pass floor (score ≥ 10/20 or ≥ 30/60) with decision "ADMIS".
  • Hardcoded Jury Rules: Auto-enforces regulatory jury composition for Proforma Institut and Proskills Institut.
  • Hybrid PDF Engine: Local libreoffice-convert in development with automatic fallback to CloudConvert REST API on Vercel.

3. System Architecture & API Endpoint Specifications

3.1 REST API Endpoint Specifications

Endpoint Method Input Payload Functionality & Output
/api/upload POST FormData (EDOF file) Parses AUTOMATISATION sheet, validates mandatory fields, updates Neon PostgreSQL DB.
/api/candidates GET/DELETE None Returns candidate list or clears database for a new training cohort.
/api/generate POST Candidate object + API key Evaluates candidate against mapping rules (pilot-mapping.json), generates DOCX/PDF files.
/api/download POST Candidates array Assembles candidate documents into a structured ZIP archive for instant browser download.
/api/drive POST Candidate object Uploads generated files directly to Google Shared Drive via OAuth Service Account.
/api/analyze POST Candidates array Sends dataset to Claude AI model for deep data audit and compliance recommendations.
/api/settings GET/POST Settings JSON Inspects and updates environment configuration (API keys, DB health, Drive folder ID).

4. Comprehensive User Manual (Step-by-Step Guide)

1
Accessing Platform & Authentication

Navigate to https://certiflow-ten.vercel.app/. Enter username admin and password Certiflow@2026.

2
Ingesting Candidate Data

Click "Charger EDOF.xlsx" and select your official EDOF workbook. Candidates are categorized into PRET_GENERATION_CLASSIQUE or PRET_GENERATION_WEDOF.

3
Running AI Quality Audit

Click "Analyse IA Fichier". Claude AI scans rows to flag incomplete records, missing birth dates, or mark anomalies before document assembly.

4
Generating Certificate Packages

Single Candidate: Click "Générer Documents" on the candidate row.
Batch ZIP: Select candidate rows and click "Télécharger Package ZIP".
Auto-Mode: Toggle "Auto-mode: ACTIF" in the navbar for hands-free background generation.

5
Synchronizing to Google Shared Drive

Click "Envoyer vers Google Drive" in the preview modal to upload files directly into your Google Shared Drive folder.

6.2 Error Diagnostic Matrix

Symptom / Error Root Cause Resolution Step
Vercel 504 Gateway Timeout Serverless function exceeded 60s limit on free plan during PDF conversion. Upgrade to Vercel Pro (configured with maxDuration: 300) or leave CLOUDCONVERT_API_KEY empty to deliver DOCX instantly.
Google Drive Permission Error Service Account email lacks Editor rights on target Shared Drive folder. Open Google Drive folder settings ➔ Share ➔ Add Service Account Email as Editor.
Template File Not Found Missing template file corresponding to certification code (e.g. RS5520). Verify file exists in templates/ directory and matches lib/certiflow/pilot-mapping.json.
Invalid Claude API Key Anthropic API key quota depleted or key expired. Check billing at console.anthropic.com and update key in Settings modal.
